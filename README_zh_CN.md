Neo是一款极致简约的思源笔记主题，在原生外观基础上优化大量细节，并引入现代化的视觉特性
#### 更新说明
- 修复Kmind插件弹窗不可见的问题
- 为部分插件设置页添加毛玻璃效果：叶归、任务笔记管理、STtools
- 提升与部分插件的兼容性
#### 重要提醒
- 仅适配思源3.7.0开发版或更高版本
- 为保证主题的最佳性能，部分样式依赖Neo+插件实现，因此必须搭配Neo+插件使用，否则无法正常显示
- Neo+插件为Neo主题提供了大量配色、样式扩展
- Neo主题使用了大量前沿CSS特性，仅保证在桌面端和Chromium内核浏览器上的完整体验
#### 特性
- 使用OKLCH色彩空间严格构建色彩体系，支持完全自定义主题色和配色扩展
- 全局使用毛玻璃效果，通透且富有层次感
- 添加非线性动画，提升交互乐趣
- 为题头图添加电影级视差效果，为编辑器添加卷轴动效，带来震撼的视觉张力
- 全局使用平滑圆角，引入渐隐效果，消除界面割裂
- 为搜索列表添加卡片排列效果，提升阅读效率
- 引入超级融合效果，将面包屑与正文无缝融合
- 优化全局文字排版，提升中英文阅读体验
- 重构全局组件样式，带来一致且优雅的界面风格
- 为手机端添加全局通透玻璃效果
- 媲美默认主题的优异性能
> 部分特性依赖Neo+插件
