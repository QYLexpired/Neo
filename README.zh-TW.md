# Neo：精心打磨的介面，靈動自由的思維
Neo 是專為思源筆記設計的第三方主題，以 Apple（macOS/iOS）設計語言為靈感，建構全域統一的精緻介面，讓每次筆記體驗都賞心悅目

## 特性
#### 豐富嚴謹的配色
- 內建數十種風格各異的預設配色方案
- 自訂主題色：可透過選取主題色與飽和度自訂介面顏色
- 主題色可跟隨時間、題頭圖或系統強調色
- 隨機配色：每次啟動思源，從所有配色方案中隨機選擇
#### 千變萬化的介面
- 超級融合：將頁籤欄、麵包屑、題頭圖和筆記正文無縫融合（源自 Asri 主題）
- IDE 風格：重塑介面語言，採用線條分區的極簡風格（源自 Asri 主題）
- 側欄靜音：凸顯編輯器區域，讓正文與側欄更具層次感
- 高對比：在淺色模式下，讓頂欄、停靠欄採用深色背景
- 反轉介面色：在深色模式下，讓側欄與正文區域的背景色反轉
- 垂直頁籤：將頁籤欄垂直排列，方便查看與切換
- 全域使用毛玻璃效果，讓介面通透且富有層次感
- 引入題頭圖視差捲動與正文捲動效果，極具視覺張力
- 引入淡出效果，消除介面的割裂感
- 預設大量紋理，並支援自訂圖片紋理或背景
- 支援設定彩色資料夾
#### 自然流暢的互動
- 加入流暢的緩動動畫，提升互動樂趣與視覺流暢度
- 為搜尋結果加入卡片式排列，提升閱讀效率
- 可將斜線選單展開為多欄，並可用鍵盤方向鍵導覽
#### 得心應手的編輯
- 優化全域文字排版，提升中英文閱讀體驗
- 新增平滑游標與流體游標效果
- 可設定彩色標題與彩色列表，提升區分度
- 引入沉浸模式，自動高亮聚焦行並將其捲動至編輯器中央
- 可釘選文字工具列
- 支援列表引導線，讓列表層級更加清晰
- 支援聚焦區塊指示效果
- 支援側邊註記，以所見即所得形式呈現於編輯器側邊
