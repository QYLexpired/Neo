#### 關於主題
- **必須搭配Neo+插件**：為保證最佳性能，主題樣式依賴 Neo+ 插件實現，因此**必須**搭配 Neo+ 插件使用，否則無法正常顯示
- **相容性提醒**：主題使用了大量前沿 CSS 特性，僅保證在桌面端和 Chromium 內核瀏覽器上的完整體驗
- **問題回饋**：[Neo 主題介紹及回饋綜合帖](https://ld246.com/article/1783158376401)、[GitHub](https://github.com/QYLexpired/Neo/issues)

#### 特性
> 以下部分特性依賴 Neo+ 插件
- 媲美預設主題的優異性能
- 豐富的介面風格隨意搭配，彷彿擁有一個主題庫
- 使用 OKLCH 色彩空間嚴格建構色彩體系，提供大量預設配色，並支援自訂主題色
- 可利用思源智能體透過自然語言自動生成介面配色
- 主題色可跟隨時間、題頭圖、系統強調色變化
- 全域使用毛玻璃效果，通透且富有層次感
- 添加非線性動畫，提升互動樂趣
- 向編輯器引入題頭圖視差滾動效果及正文卷軸效果，極具視覺張力
- 引入漸隱效果，消除介面割裂
- 為搜尋列表添加卡片排列效果，提升閱讀效率
- 引入超級融合效果，將麵包屑與正文無縫融合
- 優化全域文字排版，提升中英文閱讀體驗
- 重構全域組件樣式，帶來一致且優雅的介面風格
- 為手機端添加全域通透玻璃效果
- 預設大量紋理，並支援自訂圖片背景
- 支援垂直頁籤，將視窗頁籤垂直排列，方便檢視與切換
- 支援將斜槓選單展開為多列，並透過鍵盤方向鍵進行導航
- 支援平滑游標及流體游標
- 可設定彩色標題和彩色列表，提升區分度
- 引入沉浸模式，自動高亮聚焦行並將其滾動至編輯器中心
- 可釘住文字工具欄
- 更多特性
