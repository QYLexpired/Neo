Neo is an ultra-minimalist theme for SiYuan Note that refines numerous details upon the default appearance.
> Requires the Neo+ plugin for the complete experience.
- Rigorous Color System: Theme construction powered by the OKLCH color space, achieving custom interface color schemes through effortless configuration.
- Translucent Layered Aesthetics: Global frosted glass effects that redefine the visual language.
- Dynamic Interactive Feedback: Extensive non-linear animations that elevate the joy of note-taking.
- Immersive Visual Depth: Cinematic parallax effects for header images, delivering breathtaking visual tension.
- Silky Reading Experience: Scroll-driven animations in the editor, providing an authentically tactile reading experience.
- Meticulous Detail Craftsmanship: Smooth rounded corners applied globally, paired with fade-in effects to minimize visual fragmentation.
> Heavily inspired by the Asri, Cupertino and Rem Craft themes, thanks to their creators.
