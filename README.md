Neo is an ultra-minimalist theme for SiYuan Note that refines numerous details upon the native appearance while introducing modern features such as global frosted glass effects and animations
- Global Glassmorphism / Global Frosted Glass Effect
- Extensive Non-linear Animations
- Cinematic Hero Image Parallax Effect
- Editor Scrolling Animation / Editor Scroll Effects
- Global Smooth Rounded Corners
> Heavily inspired by the Asri and Cupertino many, thanks to their creators.
