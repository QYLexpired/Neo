Neo是一款極致簡約的思源筆記主題，在原生外觀基礎上優化大量細節。
> 需配合Neo+插件以獲得完整體驗。
- 嚴謹的色彩體系：使用OKLCH色彩空間建構主題，僅需簡易配置即可實現自定義介面配色。
- 通透的層次質感：全局採用毛玻璃效果，重塑介面語言。
- 靈動的交互回饋：加入大量非線性動畫，提升筆記樂趣。
- 沉浸的視覺縱深：為題頭圖添加電影級視差效果，帶來震撼的視覺張力。
- 絲滑的閱讀體驗：為編輯器添加卷軸動效，賦予真實的閱讀體驗。
- 極致的細節打磨：全局使用平滑圓角，引入漸隱效果，減少介面割裂。
> 大量參考了 Asri 主題、Cupertino 主題、Rem Craft 主題，感謝這些主題的製作者。
