Neo 是一款極致簡約的思源筆記主題，在原生外觀基礎上優化大量細節，並引入現代化的視覺特性
#### 更新說明
##### v1.1.4
- 為非頂欄融合狀態也引入超級融合效果（實驗性）
- 超級融合預設關閉，須透過 Neo+ 開啟
- 為配色切換增加平滑過渡
- 移除活躍文檔標題動效
- 重做 Select 表單樣式
- 修復部分情況下頂欄無法拖動的問題
- 修復全螢幕查看文檔時麵包屑按鈕無法點擊的問題
- 紋理-自訂圖片支援設定圖片填充模式（等比縮放、平鋪）
- 修復從其他主題切換回 Neo 時快捷鍵被重複註冊的問題
- 提升選單項樣式的穩健性
- 優化匯出介面樣式
#### 重要提醒
- 僅適配思源 3.7.0 開發版或更高版本，在低版本思源上無法正常顯示
- 為保證主題的最佳性能，部分樣式依賴 Neo+ 插件實現，因此**必須**搭配 Neo+ 插件使用，否則無法正常顯示
- 使用了大量前沿 CSS 特性，僅保證在桌面端和 Chromium 內核瀏覽器上的完整體驗
#### 特性
- 使用 OKLCH 色彩空間嚴格建構色彩體系，支援完全自訂主題色與配色擴展
- 全域使用毛玻璃效果，通透且富有層次感
- 添加非線性動畫，提升互動樂趣
- 為題頭圖添加電影級視差效果，為編輯器添加卷軸動效，帶來震撼的視覺張力
- 全域使用平滑圓角，引入漸隱效果，消除介面割裂
- 為搜尋列表添加卡片排列效果，提升閱讀效率
- 引入超級融合效果，將麵包屑與正文無縫融合
- 優化全域文字排版，提升中英文閱讀體驗
- 重構全域組件樣式，帶來一致且優雅的介面風格
- 為手機端添加全域通透玻璃效果
- 媲美預設主題的優異性能
> 部分特性依賴 Neo+ 插件
