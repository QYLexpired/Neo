#### 关于主题
- **必须搭配Neo+插件**：为保证最佳性能，主题样式依赖Neo+插件实现，因此**必须**搭配Neo+插件使用，否则无法正常显示
- **兼容性提醒**：主题使用了大量前沿CSS特性，仅保证在桌面端和Chromium内核浏览器上的完整体验

#### 特性
> 以下部分特性依赖Neo+插件
- 媲美默认主题的优异性能
- 丰富的界面风格随意搭配，仿佛拥有一个主题库
- 使用OKLCH色彩空间严格构建色彩体系，提供大量预设配色，并支持自定义主题色
- 主题色可跟随时间、题头图、系统强调色变化
- 全局使用毛玻璃效果，通透且富有层次感
- 添加非线性动画，提升交互乐趣
- 向编辑器引入题头图视差滚动效果及正文卷轴效果，极具视觉张力
- 全局使用平滑圆角，引入渐隐效果，消除界面割裂
- 为搜索列表添加卡片排列效果，提升阅读效率
- 引入超级融合效果，将面包屑与正文无缝融合
- 优化全局文字排版，提升中英文阅读体验
- 重构全局组件样式，带来一致且优雅的界面风格
- 为手机端添加全局通透玻璃效果
- 预设大量纹理，并支持自定义图片背景
- 支持垂直页签，将窗口页签垂直排列，方便查看与切换
- 支持将斜杠菜单展开为多列，并通过键盘方向键进行导航
- 支持平滑光标及流体光标
- 可设置彩色标题和彩色列表，提升区分度
- 引入沉浸模式，自动高亮聚焦行并将其滚动至编辑器中心
- 可钉住文字工具栏
- 更多特性
